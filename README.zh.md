# dsh-vcs-panel

[English](README.md) | 中文

DeepSeek Harness 右侧栏里的版本管理插件。在右侧栏新增 `版本管理` 页签（其他语言为 `VCS`），支持 **Git** 与 **Jujutsu** 仓库的工作区改动、语法高亮 diff，以及带 lane 图的提交历史，并可在同一处完成 Git 分支与标签操作：检出、重命名、删除、合并到当前分支、把当前分支变基到另一分支、推送分支、删除或推送标签，或与上游同步。

## 功能概览

- **住在右侧栏。** 版本管理与文件、终端等页签并列，右侧栏引导页也提供入口；轮末横幅与快捷键打开同一个页签。
- **时间线与 lane 图。** 工作改动（Git 的工作区或 Jujutsu 的 `@`）固定在顶部，下方按拓扑顺序排列提交历史，展示分支、书签、标签，并可在 `HEAD` / `@` 与全部提交之间切换范围；支持多仓库工作区。
- **内联变更树。** 收起时作为可折叠文件列表浏览，展开任一文件即可在原位阅读 diff，支持文件头吸顶、单栏或左右对比、自动换行。
- **贴合 Git 与 Jujutsu 模型。** Git 显示已暂存 / 未暂存分组（未跟踪项标为 `?`）与 ahead/behind；Jujutsu 显示 `@`、变更 ID 与书签。
- **轮末横幅与全局快捷键。** 有文件改动的对话轮次末尾显示紧凑的版本管理横幅（展示该轮所在的分支或 `@`、本轮改动文件数与 `+` / `−` 行数统计），替代对话自带的改动文件卡片；在任意视图按 `⌘⇧G` / `Ctrl+Shift+G` 打开右侧栏页签，再按一次滑回对话。
- **一键同步。** Git 分支旁的按钮显示 ahead/behind 计数；点击后抓取上游，再快进或推送。分支已分叉、快进会覆盖本地改动或分支没有上游时不做改动，并提示下一步怎么做。
- **切换分支。** 分支名本身是菜单：展开仓库的本地分支，选中即检出。菜单只列本地分支，不隐式创建远程分支的本地副本；会覆盖本地改动时 Git 拒绝，面板不贮藏、不丢弃、不强制。
- **分支操作。** 右键当前分支、列表中的任一分支或提交历史里的分支徽标（也可在分支控件上按 `Shift+F10`），可检出、重命名、删除、合并到当前分支、把当前分支变基到它、推送。当前分支只提供重命名与推送。重命名、删除、合并、变基在运行前说明将发生什么；删除未合并的分支需要再次明确确认；合并或变基冲突会自动中止，分支保持不变。推送只把指定的分支送到它配置的上游，从不强制推送。
- **标签操作。** 右键提交历史里的标签徽标，可打开“删除标签…”与“推送标签…”。删除只移除本地标签，并在确认框里说明远程副本仍会保留；推送只把该标签送到选定的已配置远程，从不强制，因此远程已有不同对象时会被拒绝而不是被覆盖。推送对话框会加载仓库的远程列表，没有远程时也会说明。
- **写入都需明确操作。** 同步、分支操作与标签操作是仅有的写操作：不执行暂存、提交、强制推送、丢弃改动，也不创建分支或标签（Jujutsu 仅在读取时快照工作副本）。跟随 DSH 主题与全部 8 种界面语言，大历史与大 diff 按需加载。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `⌘⇧G` / `Ctrl+Shift+G` | 在右侧栏打开 `版本管理` 页签；页签正在显示时收起右侧栏（可在 **Settings → Shortcuts** 重绑定） |
| `↑` `↓` 或 `j` `k` | 沿一条纵向列表移动：变更树的行与展开文件的 hunk header |
| `←` `→` 或 `h` `l` | 进入变更树或展开的行；`←` / `h` 先收起展开的文件，再按才返回时间线 |
| `Enter`、`Space`、`Esc` | 折叠/展开当前行；`Esc` 返回时间线 |
| `↑` `↓`、`Home` `End` | 在展开的分支菜单或分支/标签操作菜单内移动；`Esc` 关闭菜单 |
| 右键、`Shift+F10` | 对当前分支、列表中的分支或提交历史里的分支徽标打开操作菜单；右键标签徽标打开标签操作 |
| `Enter`、`Esc` | 确认或取消分支或标签操作对话框 |
| `[` / `]` | 在变更树中移动到上一行 / 下一行，跳过 hunk header |

## 安装

需要 **DSH 0.2.2-rc.3+**（Desktop 或 Web，包含右侧栏页签与导航 API），且 `PATH` 中包含 `git` 或 `jj`。

- **界面安装：** 打开 **Plugins → Add plugin**，选择本目录后重启 DSH。
- **命令行安装：**
  ```sh
  dsh plugin --profile desktop add link:/path/to/dsh-vcs-panel
  ```
  添加后重启 DSH。可随时在 **Plugins** 中停用或卸载（卸载后恢复对话默认的改动文件卡片）。

## 开发

```sh
npm install          # 安装开发依赖 esbuild
npm run build        # 从 src/client/ 构建 client.js
npm run check        # 运行 node --test 并检查 client.js 是否为最新
npm pack --dry-run   # 检查打包内容
```

修改客户端代码请编辑 `src/client/` 并运行 `npm run build` 更新产物 `client.js`。验证 `dsh plugin` 安装、升级与卸载时请使用临时 `DSH_HOME`，保持真实 profile 独立。
